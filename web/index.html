How it works

APY = ((1 + net profit / investment)365 / days − 1) × 100%

Uses actual elapsed days and a 365-day year. Assumes the same return repeats and profits are reinvested, with no additional deposits or withdrawals. This is not a forecast or a quoted deposit-account yield.
